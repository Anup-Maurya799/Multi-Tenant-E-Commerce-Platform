# Project Analysis

## Actors

1. Super Admin

- Manage all vendors
- View all stores
- Manage the platform

2. Vendor

- Register/Login
- Create Store
- Add Products
- Update Products
- View Orders

3. Customer

- Register/Login
- Browse Products
- Add to Cart
- Place Orders
- Make Payment

## Main Collections

- Users
- Stores
- Products
- Categories
- Cart
- Orders
- OrderItems
- Payments
- Reviews

## Collection Purpose

Users
Stores login information for Admins, Vendors and Customers.

Stores
Stores information about each vendor's shop.

Products
Stores all products.

Categories
Groups products.

Cart
Stores customer shopping carts.

Orders
Stores completed orders.

OrderItems
Stores individual products in each order.

Payments
Stores payment details.

Reviews
Stores customer ratings and reviews.
